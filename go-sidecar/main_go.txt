// dialUTLS abre la conexion (directa o via proxy) y hace el handshake TLS\par
// con un ClientHello clonado de Chrome (uTLS) en vez del ClientHello nativo\par
// de Go, que de otra forma delataria el binario como trafico no-navegador.\par

// Se conecta como NetDialTLSContext del Dialer de gorilla/websocket en vez\par
// de usar el campo Proxy nativo de gorilla a proposito: gorilla tiene un\par

// asi que el tunel CONNECT se maneja entero aca adentro.\par

\tab\tab rawConn, err = connectThroughProxy(ctx, proxy, addr)\par
\tab\} else \{\par
